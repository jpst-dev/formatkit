## Which file to pick

- **`FormatKitUI.exe`**: the window. For most people.
- **`formatkit.exe`**: the command line, for scripts and the terminal.

They are independent files: you only need one of them. Both are self-contained, run on **Windows 11 x64** and **need no .NET install**.
