## Which file to pick

- **`FormatKitUI.exe`**: the window. For most people.
- **`formatkit.exe`**: the command line, for scripts and the terminal.

They are independent files: you only need one of them. Both are self-contained, run on **Windows 11 x64** and **need no .NET install**.

<DownloadCard />

## Update

You only download once. After that, the window tells you on its home page when a new version exists and installs it with **Update now**. On the command line, use `formatkit update`.

The new files are checked before they replace the current ones, and any failure keeps the current ones. Updating is refused while a run is interrupted or waiting for a reboot: finish the run first. The notice can be turned off on the About page. Versions before 0.3.0 do not have this option, so from those you download the new one by hand one last time.
