Cada item tem um **nível**: *Seguro* serve para todo mundo, *Equilibrado* é para quando você não usa o recurso, e *Agressivo* só vale se você entende a troca. Um item **contestado** é um ajuste sobre o qual especialistas discordam. Um item **sensível em notebooks** pode custar bateria ou atrapalhar a suspensão. Alguns itens **precisam reiniciar** o PC.

Itens da categoria Desenvolvedor nunca são escolhidos por um nível: só são aplicados se você os listar em `include` no perfil, e alguns reduzem proteções.

Abra um item para ver o que ele faz, o que pode quebrar e o comando para desfazer.
