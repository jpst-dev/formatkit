## Qual arquivo escolher

- **`FormatKitUI.exe`**: a janela. Para a maioria das pessoas.
- **`formatkit.exe`**: a linha de comando, para scripts e terminal.

São arquivos independentes: você só precisa de um deles. Os dois são autocontidos, funcionam no **Windows 11 x64** e **não exigem instalar o .NET**.

<DownloadCard />

## Atualizar

Você só baixa uma vez. Depois, a janela avisa na tela inicial quando há uma versão nova e instala com **Atualizar agora**. Na linha de comando, use `formatkit update`.

Os arquivos novos são conferidos antes de substituir os atuais, e qualquer falha mantém os atuais. A atualização é recusada enquanto uma execução estiver interrompida ou esperando um reinício: termine a execução primeiro. O aviso pode ser desligado na página Sobre. Versões anteriores à 0.3.0 não têm essa opção: nelas, baixe a versão nova à mão uma última vez.
